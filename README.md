This is the `arcs_cohort_navigation` ROS 2 package, part of the [CoHORT](https://github.com/csun-arcs/arcs_cohort) multi-rover autonomy software stack.

## 📝 Description

A navigation package based on ROS 2 Nav 2 for the CSUN ARCS CoHORT project.
